3.3 Dua skill baru hasil riset

A. local-llm-serving — menggantikan serving-llms-vllm, inference-sh-cli, dan menutup jalur model llama-cpp. - Binari dibangun dari source pada tag v0.5.0 (commit 7fe450e), statis (-DBUILD_SHARED_LIBS=OFF), tanpa sudo, tanpa curl | sh. - API kompatibel OpenAI: /health, /v1/models, /v1/chat/completions. - Model: qwen2.5-0.5b-instruct-q4_k_m.gguf — sha256 74a4da8c9fdbcd15bd1f6d01d621410d31c6fc00986f5eb687824e7b93d7a9db, 491.400.032 byte, terverifikasi sebelum dipakai. - Kenapa melebihi: skill lama memerlukan runtime vLLM yang tidak dapat dipakai sama sekali di host tanpa GPU; jalur ini terbukti melayani (batching paralel terukur) dan tidak bergantung SaaS pihak ketiga.

B. realtime-visual-engine — menggantikan touchdesigner-mcp. - Pipeline: Chromium headless (Playwright) + WebGL/GLSL → frame → ffmpeg h264. - Kenapa melebihi: skil lama mengasumsikan aplikasi proprietary yang tidak ada di host; pengganti ini jalan di host, tanpa lisensi, lintas platform, dan dapat dikendalikan agen lewat jalur kontrol eksternal (UDP/OSC stdlib).

5. Sisa batasan (jujur)

  1. Kecepatan CPU: 0,5B q4 pada CPU berbagi beban ≈ 16 tok/s single. Ini bukan pengganti GPU untuk beban produksi besar.
  2. FPS visual software-GL ≈ 6–12 fps pada 480×270 (SwiftShader). Pengganti setara TouchDesigner hanya bila GPU tersedia; jangan klaim "60 fps".
  3. Fitur visual lanjutan (live video-in, mixing multi-layer, MIDI penuh) belum ada; butuh pass shader tambahan/pustaka OSC.
  4. Model & tool pihak ketiga tetap butuh audit berkala; versi dipin hari ini bisa berubah besok.
  5. release_check.py tanpa --project memang FAIL (gate proyek, bukan gate ekosistem) — dijalankan per-target saat rilis, bukan untuk pekerjaan ini.
  6. Skill pihak ketiga (Superpowers, Trail of Bits, Sentry, Anthropic, GitHub MCP, Context7, Crawlee, axe-core, Lighthouse) masih PENDING_APPROVAL Owner — tidak ada yang dipasang diam-diam.
