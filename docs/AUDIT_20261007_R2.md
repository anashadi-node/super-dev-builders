## Temuan yang Sudah Diperbaiki (commit `3d90fad`, repo utama; `8346e6d` + `471ef28`, suite)

1. **geo_scan.py** — target URL ad-hoc diverifikasi lewat `fetch()` tanpa pengaman.
   Perbaikan: tolak skema non-http (`file://` = risiko baca file lokal), batas respons 5 MB,
   XML sitemap menolak DTD/ENTITY (mitigasi XXE/billion-laughs), rate limit 1 req/detik.
2. **Bug logika robots.txt** — beberapa baris `User-agent:` berurutan (satu grup menurut
   RFC 9309) hanya dihitung yang terakhir → Disallow untuk GPTBot/ClaudeBot bisa terbaca
   "allowed" sehingga verdict audit GEO keliru. Sudah diperbaiki + ada test reproduksi
   (`test_parse_robots_grouped_user_agents`, `test_parse_robots_groups_not_merged_across_rules`).
3. **`llms.txt` yang di-redirect** dulu dilaporkan PASS — kini FAIL jika redirect
   (PerplexityBot menolak follow redirect).
4. **`crawl-delay` dijanjikan di SKILL.md tapi tidak dicek kode** — kini diimplementasi dan
   dilaporkan bila > 10 detik.
5. **Drift + tabrakan nama skill** — dulu tidak terdeteksi. Sekarang doctor membandingkan isi
   file (bukan hanya stat) dan menandai COLLISION bila nama skill dimiliki 2 pihak. Temuan
   nyata: `evidence-normalizer` (suite) vs `evidence-normalizer` (SDB). Konten unik suite
   digabung ke `skills/evidence-normalizer/references/multi-platform-capture.md`; salinan
   lama dipindah (tidak dihapus) ke `~/backups/sdb-audit-20261007_104713/`.
6. **39 test bawaan `skills/*/tests`** dulu tidak pernah ikut `make test` — kini
   `testpaths=["tests","skills"]` di pyproject.toml dan ruff juga memindai `skills/`.
7. **Pin versi exact** — paket harus punya revisi yang diaudit:
   `@playwright/mcp@0.0.83`, `@gavrix/appium-mcp@0.3.0`, `@alibaba-group/open-code-review@1.12.12`,
   `web-embedding@0.3.10`. Catatan: appium-mcp tidak di-update sejak 2025-07 → review manual
   sebelum dipakai di data sensitif.
8. **Makefile baru**: `lint`, `drift`, `check` (gerbang lokal sebelum commit).
9. **Dokumentasi hitungan "21 skill"** yang basi — kini merujuk registry (37).
